## Caveats (recorded, not argued away)

- Arm order was fixed: ring-default, then ring-8192, then
  striding-off. The striding arm ran last, so an order or history
  effect is not excluded by design. The two ring arms (both 8/8)
  argue against a simple "the failure stopped happening later in the
  session" reading, but a counterbalanced repeat is the clean test
  and would need PI approval as a new run.
- The queue-7 NAPI thread pid changed across config changes
  (rediscovery logged per arm; final pid 2017815).
- Cells used the full task 1 cell flow (flood to the WEDGE detector,
  REDUCE, 120 s monitor, 10k probe), so the recovery columns above
  are the task 1 definitions.
