## Method and caveats

- Every table value above was read from the named file (git blob, source-archive diff, SRPM, or recorded `/boot/config` dump) — no value is inferred from defaults except where explicitly noted (Android NO_HZ_FULL absent from gki_defconfig = Kconfig default n).
- Ubuntu annotation policies are written per-arch (`{'amd64': ...}`); the noble annotations file contains no `amd64-lowlatency`-style flavor keys for these symbols, so the arch-level value covers every flavor built from that source package (generic and lowlatency). The cloud flavors are separate source packages and were checked separately (rows 4-6, including their per-flavor annotation files).
- Web UIs that bot-wall plain fetches (kernel.ubuntu.com cgit, git.launchpad.net cgit, salsa.debian.org Anubis, src.fedoraproject.org Anubis, android.googlesource.com raw) were read through their git protocol / packaging archives / SRPMs instead; URLs above point at the same content.
- Ubuntu 24.04 HWE kernels (6.11/6.14/…) are separate source packages and were NOT surveyed in this pass (no `Ubuntu-6.11.0-*`/`6.14.0-*`/`6.17.0-*` tags on the ubuntu-noble repo); the 24.04 rows cover the GA 6.8 series.
- UNKNOWN items: (a) AL2023 kernel-6.18 config — the `amazonlinux/linux` GitHub repo ships no config files (checked repo root and `amazon-6.1.y/*` branches), and the 6.18 SRPM was not pulled; (b) COS current-milestone (129 LTS) config — `chromiumos/overlays/board-overlays` main/master carry only 4.19/5.4-era lakitu configs, `chromiumos/third_party/lakitu-kernel` is 4.19-era, and `cos/overlays/board-overlays` is not reachable over git ("repository not found"); the recorded 6.1.85+ dump values are cited instead. Neither UNKNOWN affects the combo determination for those rows as far as verified values go.
- The measurement node's own kernel (custom 6.17.8, IRQ_TIME_ACCOUNTING unset, NO_HZ_FULL=y) is recorded in AN-007 and is the config the 166x number was measured on; per DR-013 the paper states the 166x only for the measured configurations and names which distributions ship them (this table).
